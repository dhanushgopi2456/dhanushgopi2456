`React` `Vite` `Node.js` `Express` `MongoDB` `Mongoose`
A full-stack e-commerce application with JWT authentication, a responsive React frontend, and an admin dashboard for complete inventory control. Modular, scalable REST APIs power secure user, product, and cart management workflows.

#### ✅ [Team Task Manager](https://github.com/dhanushgopi2456/Team-Task-Manager)
`React.js` `Node.js` `Express.js` `MongoDB` `Mongoose` `JWT` `Tailwind CSS`
A collaborative, multi-user task management system with JWT-based Role-Based Access Control (RBAC) and an MVC-based modular backend. Features a responsive UI with real-time state updates and custom filters.

#### 🎯 [Object Detection using YOLOv9](https://github.com/dhanushgopi2456/Object-Detection-YOLO-v9)
`Python` `PyTorch` `OpenCV` `NumPy` `Flask`
An end-to-end computer vision pipeline using YOLOv9 for real-time custom model training and benchmarking, deployed as a Flask web app for live inference on media files. Research published at AIDE-2024.
